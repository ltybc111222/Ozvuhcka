# Odyssey Quest — студия озвучки

Озвучка сценария главы 1 через Gemini TTS (`gemini-3.8-flash-tts`). Сценарий — `data/voiceScript.json`
(персонажи с голосами и инструкциями стиля, 43 реплики RU и EN, пути файлов игры).

## Как пользоваться
1. Открыть в Google AI Studio (Build → импорт из GitHub) — ключ Gemini подставится сам.
   Локально: `npm i`, создать `.env.local` с `GEMINI_API_KEY=...`, `npm run dev`.
   На Маке с ключом в связке ключей (`security add-generic-password -a "$USER" -s gemini-api-key -w`): `npm run dev:mac`.
2. Слева реплики по папкам; точки — RU/EN: серая нет записи, зелёная готово, жёлтая устарело
   (поменяли текст, голос или стиль), красная ошибка.
3. Голос и инструкция стиля — общие для персонажа. Текст правится прямо в карточке,
   метки `<short pause>`, `<long pause>`, `<sigh>`, `<exhales>` и знак ударения — кнопками.
4. «Озвучить недостающее» — очередь по фильтру, пауза между запросами, два повтора на ошибке.
5. «↻ Ещё дубль» не затирает прежнюю запись: она уходит в «Прежние дубли» (до 6), любой можно
   послушать и сделать выбранным (★). В zip и в игру идёт выбранный.
6. Слушаем уже с доводкой как в игре: тишина по краям ≤ 0,1 с с затуханием, −16 LUFS, пик −2 dBFS.
   Галка «сырой» — сравнить с тем, что прислал Gemini. У реплик боссов видна норма длины из README «Озвучка».
7. «Скачать всё (zip)» — доведённые WAV 24 кГц с путями игры (`ch01/voice/<папка>/<файл>[.ru].wav`) и
   `manifest.json` (статус, длина, LUFS, пик). В игру: `node tools/voice/import-studio-zip.mjs <zip>` в game-sod.

Ответ Gemini — это WAV с блоком C2PA в хвосте, а не голый PCM. Студия достаёт из него отсчёты;
записи, сохранённые до исправления (щелчок в начале, шум и обрыв в конце), лечатся при открытии.

Записи и правки хранятся в браузере (IndexedDB) и не пропадают при перезагрузке.
Новый сценарий — кнопка «Открыть JSON».

## Рассказчик

Вкладка «Рассказчик» (открывается по умолчанию): рассказ Сэма по всему лору главы 1, 15 фрагментов в `data/narration.json`, один голос (Algenib) и общий стиль. Каждый фрагмент озвучивается отдельным запросом; «Озвучить недостающее» идёт очередью. Скачать можно фрагменты zip-архивом или всё одним WAV с паузой 1,2 с между частями. Правки текста и голоса сохраняются в браузере.
